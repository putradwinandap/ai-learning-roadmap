# Origin story

This repo started as one developer's personal learning tracker.

The author spent 8 years as a WordPress developer and decided to move into:

1. **Modern fullstack development** (React, TypeScript, Next.js, modern backends)
2. **Enterprise-level engineering**
3. **AI engineering** (applied AI / LLM engineering)

The original repo was a roadmap, a daily/weekly tracker built on GitHub Issues, a public portfolio of progress, and a place for notes and projects. Its principles were:

- Consistency over perfection
- Fundamentals first, then AI
- Use AI tools wisely, never as a replacement for understanding
- Focus on production-ready skills, not just following tutorials

While following that path, it became clear that the same structure could help anyone: clear levels, a real project per level, and an AI assistant that holds you to a standard instead of doing the work for you. So the repo was rebuilt into the open curriculum you see now. The principles stayed the same.
