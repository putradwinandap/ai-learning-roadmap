# AI Learning Roadmap

**WordPress Developer → Modern Fullstack → Enterprise → AI Engineer**

Repo ini dibuat untuk tracking perjalanan belajar saya secara disiplin dan transparan.

## Tujuan Repo Ini

Saya punya background 8 tahun sebagai WordPress developer. Sekarang saya ingin hijrah ke:

1. **Modern Fullstack Development** (React, TypeScript, Next.js, backend modern)
2. **Enterprise-level Engineering**
3. **AI Engineering** (Applied AI / LLM Engineering)

Repo ini berfungsi sebagai:

- **Roadmap utama** → Semua rencana belajar ada di sini
- **Daily / Weekly tracker** → Setiap tugas akan dibuatkan GitHub Issue
- **Portfolio progress** → Orang lain (termasuk recruiter) bisa lihat konsistensi dan progress saya
- **Dokumentasi belajar** → Catatan, insight, dan project akan ditaruh di sini juga

## Cara Pakai Repo Ini

- Setiap **Issue** = 1 tugas (harian atau mingguan)
- Issue yang selesai akan di-**close**
- Label dipakai untuk kategori (`foundation`, `frontend`, `backend`, `ai`, `project`, `review`)
- Bisa pakai GitHub Projects untuk melihat overview progress

## Struktur Folder (akan berkembang)

```text
/
├── README.md
├── notes/             # Catatan belajar
├── projects/          # Project selama roadmap
├── resources/         # Link & materi penting
└── weekly-review/     # Review mingguan
```

## Prinsip Belajar

- Konsisten > Sempurna
- Fondasi dulu, baru AI
- Pakai AI tools dengan bijak (bukan menggantikan pemahaman)
- Fokus ke kemampuan **production-ready**, bukan cuma ikut tutorial
