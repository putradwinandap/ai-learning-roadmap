# Level 01: Programming Fundamentals

> The building blocks every program in every language is made of. Master these and every later level gets easier.

## Goals

By the end of this level you can:

- Store and transform data with variables, types and operators.
- Control the flow of a program with conditionals and loops.
- Break a problem into small, reusable functions.
- Work with collections (lists/arrays and dictionaries/maps).
- Read user input, format output, and save/load data from files.
- Handle errors without crashing, and debug systematically.
- Organise a small program so others (and future you) can read it.

## Prerequisites

[Level 00](../00-mindset-and-tools/) passed: your language runtime is installed and you can use the terminal and Git.

## Time estimate

30–50 hours.
