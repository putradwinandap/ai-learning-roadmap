# Level 09: AI Engineering

> Build reliable products on top of large language models: retrieval, tools, agents, evaluation, safety and cost, with the same engineering discipline as everything before.

## Goals

By the end of this level you can:

- Explain how LLMs work at a practical level: tokens, context windows, sampling, capabilities and failure modes.
- Call LLM APIs effectively: prompting, structured output, streaming, error handling, retries.
- Build retrieval-augmented generation (RAG): chunking, embeddings, vector search, hybrid search, reranking, citations.
- Give models tools and build agents with safe, observable loops.
- Evaluate LLM systems with datasets, automated metrics, LLM-as-judge and human review, and catch regressions in CI.
- Defend against prompt injection, data leakage and unsafe actions.
- Manage latency and cost with caching, model selection and batching.
- Operate AI features in production: tracing, feedback loops, versioned prompts.

## Prerequisites

[Level 08](../08-enterprise-engineering/) passed. You'll need access to at least one LLM API (many providers have free tiers) or a local model runtime (e.g. Ollama).
