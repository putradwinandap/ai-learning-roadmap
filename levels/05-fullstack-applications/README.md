# Level 05: Fullstack Applications

> Connect a modern frontend to your backend and ship a real product to the internet.

## Goals

By the end of this level you can:

- Build a UI with a component-based framework (React, Vue, Svelte, Angular, ...).
- Use TypeScript (or your language's typed equivalent) across the frontend.
- Manage client state, server state and forms properly.
- Implement a secure authentication flow between frontend and backend.
- Handle routing, loading, errors and optimistic updates.
- Choose between client-side rendering, server-side rendering and static generation.
- Deploy a frontend, a backend and a managed database, with environment-specific config.

## About languages in this level

The UI runs in the browser, so the frontend uses **JavaScript/TypeScript**. Your **backend stays in your chosen language** (you'll extend your Level 04 API). Fullstack JS frameworks (Next.js, Nuxt, SvelteKit, Remix) are allowed if your backend is JS/TS.
