# Level 05 language tracks

The frontend is TypeScript for everyone. The backend is your Level 04 language.

| Track | Status |
|---|---|
| React + TypeScript (frontend) | planned |
| Vue + TypeScript (frontend) | planned |
| Next.js (fullstack TS) | planned |
| Backend extensions per language (Python, Go, Java, C#, PHP, ...) | planned |

Until a track exists, your AI mentor teaches with examples in your chosen framework and backend language, and grades with the core rubric only.
