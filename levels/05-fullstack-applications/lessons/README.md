# Level 05 topics

Full lesson files are planned. Until then, your AI mentor teaches these topics in order (`/lesson`), using the resources below.

| # | Topic | Key ideas |
|---|---|---|
| 01 | TypeScript essentials | Types, interfaces, unions, generics, narrowing, strict mode |
| 02 | Component thinking | Components, props, composition, one-way data flow, lists and keys |
| 03 | State | Local state, lifting state, derived state, global state and when you *don't* need it |
| 04 | Server state | Fetching, caching, invalidation, loading/error states (e.g. TanStack Query, SWR, framework loaders) |
| 05 | Forms | Controlled inputs, validation (shared schemas), accessible errors, submission states |
| 06 | Routing | Client-side routing, nested routes, protected routes, URL as state |
| 07 | Auth in the browser | Cookie sessions vs tokens in the browser, CSRF, CORS with credentials, logout everywhere |
| 08 | Rendering strategies | CSR, SSR, SSG, hydration, when each fits |
| 09 | Styling at scale | CSS modules, utility CSS, design tokens, component libraries and their trade-offs |
| 10 | Frontend testing | Component tests (Testing Library), end-to-end tests (Playwright), what to test where |
| 11 | Deployment | Build pipelines, environment variables per environment, hosting frontends, hosting APIs, managed databases, domains and HTTPS |
| 12 | Performance basics | Bundle size, code splitting, images, Core Web Vitals |
