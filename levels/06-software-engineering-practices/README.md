# Level 06: Software Engineering Practices

> Work like a professional team: automated quality checks, reproducible environments, safe releases and good collaboration habits.

## Goals

By the end of this level you can:

- Design a test strategy using the testing pyramid, and measure coverage meaningfully.
- Containerise applications with Docker and run multi-service setups with Compose.
- Build CI/CD pipelines that lint, test, build and deploy automatically.
- Use a team Git workflow: branches, pull requests, code review, protected branches, semantic versioning.
- Manage dependencies and keep them secure and up to date.
- Write useful documentation: READMEs, contributing guides, changelogs, ADRs (intro).
- Refactor legacy code safely.

## Prerequisites

[Level 05](../05-fullstack-applications/) passed. This level builds directly on your Level 05 project.
