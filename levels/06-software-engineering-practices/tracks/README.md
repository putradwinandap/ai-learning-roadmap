# Level 06 language tracks

Most of this level (Docker, CI/CD, Git workflow) is language-independent. Tracks will cover language-specific testing, coverage, linting and container practices.

| Track | Status |
|---|---|
| Python (pytest, coverage, Ruff, mypy, Docker images) | planned |
| JavaScript/TypeScript (Vitest, Playwright, ESLint, Node Docker images) | planned |
| Go, Java, C#, PHP, ... | planned |

Until a track exists, your AI mentor recommends the standard tools for your stack and grades with the core rubric only.
