# Level 06 topics

Full lesson files are planned. Until then, your AI mentor teaches these topics in order (`/lesson`), using the resources below.

| # | Topic | Key ideas |
|---|---|---|
| 01 | Testing strategy | Testing pyramid/trophy, unit vs integration vs E2E, contract tests, flaky tests, meaningful coverage |
| 02 | Test doubles & test data | Mocks, stubs, fakes, factories, test containers |
| 03 | Docker fundamentals | Images, containers, layers, Dockerfile best practices, multi-stage builds, `.dockerignore` |
| 04 | Docker Compose | Multi-service local environments, networks, volumes, health checks |
| 05 | Continuous integration | Pipelines, jobs, caching, matrix builds, required checks (GitHub Actions) |
| 06 | Continuous delivery/deployment | Build once, deploy many. Environments, secrets in CI, rollbacks |
| 07 | Team Git workflow | Trunk-based vs GitFlow, PRs, rebasing vs merging, conventional commits, protected branches |
| 08 | Code review | What to look for, giving and receiving feedback, PR size, review checklists |
| 09 | Dependencies & supply chain | Lockfiles, semantic versioning, Dependabot/Renovate, vulnerability scanning |
| 10 | Static analysis | Linters, formatters, type checkers, pre-commit hooks |
| 11 | Documentation | README, CONTRIBUTING, CHANGELOG, ADRs, runbooks |
| 12 | Refactoring legacy code | Characterisation tests, small safe steps, strangler pattern |
