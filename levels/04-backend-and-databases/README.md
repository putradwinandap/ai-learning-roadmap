# Level 04: Backend & Databases

> Build the server side: APIs that validate input, store data safely in a relational database, and authenticate users.

## Goals

By the end of this level you can:

- Design a RESTful API: resources, methods, status codes, error format, pagination.
- Build an HTTP server with a web framework in your language.
- Model data relationally and write SQL: joins, aggregates, indexes, transactions.
- Use migrations and a database access layer (query builder or ORM) without losing sight of the SQL.
- Validate input at the boundary and return consistent errors.
- Implement authentication (password hashing, sessions or tokens) and authorization.
- Configure apps with environment variables and keep secrets out of code.
- Write integration tests for API endpoints.
