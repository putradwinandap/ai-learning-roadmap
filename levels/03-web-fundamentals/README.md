# Level 03: Web Fundamentals

> Understand how the web actually works: requests, responses, documents, styles and scripts. No framework yet.

## Goals

By the end of this level you can:

- Explain what happens between typing a URL and seeing a page (DNS, HTTP, rendering).
- Read and reason about HTTP requests and responses: methods, status codes, headers, JSON bodies.
- Write semantic, accessible HTML.
- Lay out responsive pages with CSS (box model, Flexbox, Grid, media queries).
- Use JavaScript in the browser: DOM, events, `fetch`, async/await.
- Use browser DevTools to debug layout, network and scripts.
- Deploy a static site.

## About languages in this level

The browser runs **HTML, CSS and JavaScript** only, so this level requires JavaScript regardless of your chosen language. (Languages that compile to JS, like TypeScript, are fine.) Your backend language comes back in Level 04.
