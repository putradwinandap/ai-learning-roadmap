# Level 03 topics

Full lesson files are planned. Until then, your AI mentor teaches these topics in order (`/lesson`), using the resources below.

| # | Topic | Key ideas |
|---|---|---|
| 01 | How the web works | Client/server, URLs, DNS, TCP/TLS at a high level, browsers |
| 02 | HTTP | Methods, status codes, headers, cookies, JSON bodies, `curl`, DevTools Network tab |
| 03 | Semantic HTML | Document structure, landmarks, headings, forms and labels, links vs. buttons |
| 04 | CSS fundamentals | Cascade, specificity, box model, units, colors, typography |
| 05 | Layout | Flexbox, Grid, responsive design, media queries, mobile-first |
| 06 | Accessibility | WCAG basics, keyboard navigation, focus, ARIA (sparingly), contrast, screen readers |
| 07 | JavaScript in the browser | DOM querying and updating, events, event delegation, forms |
| 08 | Asynchronous JavaScript | Event loop, promises, async/await, `fetch`, error handling, loading states |
| 09 | Browser storage & security | `localStorage`, CORS, same-origin policy, XSS and why `innerHTML` with user data is dangerous |
| 10 | Tooling & deployment | DevTools, Lighthouse, a simple dev server, deploying to GitHub Pages / Netlify |
