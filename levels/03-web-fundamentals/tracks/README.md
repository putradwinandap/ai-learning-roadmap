# Level 03 language tracks

This level runs in the browser, so the project is **HTML + CSS + JavaScript** for everyone.

| Track | Status |
|---|---|
| JavaScript | planned (browser-specific idioms, ESLint browser config) |
| TypeScript | planned (compiling with `tsc` or Vite) |

Learners whose main language is Python, Go, Java, etc. follow the core lessons. Your mentor connects new ideas to what you know (for example, comparing JavaScript promises with Python's `asyncio`).

Want to add a track? See [docs/adding-a-track.md](../../../docs/adding-a-track.md).
