# Level 08: Enterprise Engineering

> Build software the way large organisations need it: modular, observable, secure, compliant, automated, and maintainable by many teams for years.

## Goals

By the end of this level you can:

- Structure a large system with domain-driven design: bounded contexts, modules and service boundaries.
- Decide between a modular monolith and microservices, and implement either well.
- Communicate between services synchronously (REST/gRPC) and asynchronously (events).
- Make systems observable with structured logs, metrics, distributed traces, dashboards and SLO-based alerts.
- Apply enterprise security: threat modelling, OWASP ASVS, OAuth 2.0/OIDC and SSO, secrets management, audit logging.
- Provision cloud infrastructure with Infrastructure as Code.
- Support multi-tenancy, data protection and compliance requirements.
- Document architecture with ADRs, C4 diagrams and runbooks, and run incidents and postmortems.
