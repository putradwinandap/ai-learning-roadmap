# Level 07: System Design & Architecture

> Think beyond one server: design systems that stay fast, correct and available as load grows, and explain your trade-offs.

## Goals

By the end of this level you can:

- Gather requirements (functional and non-functional) and do back-of-the-envelope estimates.
- Explain scaling strategies: vertical/horizontal scaling, load balancing, statelessness.
- Use caching correctly: where, what, how long, and how to invalidate.
- Use queues and asynchronous processing: background jobs, retries, idempotency, dead-letter queues.
- Reason about data at scale: replication, partitioning/sharding, consistency models, CAP/PACELC.
- Design APIs for evolution: versioning, pagination, rate limiting, idempotency keys.
- Write a design document and defend it in a design review.
- Measure performance with load tests and profiling.
