# Level 00 rubric add-on: Python

These criteria are added to the [core rubric](../../rubric.md) and count toward the average.

| ID | Criterion | 3 = meets | 4 = exceeds | Typical 1–2 signs |
|---|---|---|---|---|
| L00-PY-R1 | **Pythonic basics** | Uses f-strings for formatting, `.strip()` on input, `snake_case` names, `ruff format` leaves the file unchanged, and `ruff check` reports no errors. | Imports at the top. Code organised so the main flow is easy to follow (a `main()` function with `if __name__ == "__main__":` is a bonus at this level). | String concatenation with `+` and `str()` everywhere, camelCase names, formatter not applied, lint errors. |
