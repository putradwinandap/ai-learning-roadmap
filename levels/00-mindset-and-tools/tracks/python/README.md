# Level 00: Python track

## Versions and tools

| What | Use |
|---|---|
| Python | **3.12 or newer** |
| Run a file | `python hello.py` (macOS/Linux may need `python3`) |
| Formatter + linter | [**Ruff**](https://docs.astral.sh/ruff/) (`ruff format`, `ruff check`) |
| Editor extension (VS Code) | "Python" (Microsoft) + "Ruff" (Astral) |
| Optional: package/version manager | [`uv`](https://docs.astral.sh/uv/) |

## Lessons in this track

- [04: Editor and environment](lessons/04-editor-and-environment.md): installing Python, Ruff and editor setup
- [06: Your first program](lessons/06-your-first-program.md): `print`, `input`, f-strings, running a file
