## No track for your language?

You can still use it. Your AI mentor will:
- teach from the core lessons with examples in your language,
- recommend your language's standard tooling,
- grade with the core rubric only.

Want to add a track? See [docs/adding-a-track.md](../../../docs/adding-a-track.md).
