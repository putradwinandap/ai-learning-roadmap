# Level 00 rubric add-on: JavaScript

These criteria are added to the [core rubric](../../rubric.md) and count toward the average.

| ID | Criterion | 3 = meets | 4 = exceeds | Typical 1–2 signs |
|---|---|---|---|---|
| L00-JS-R1 | **Modern JS basics** | Uses `const`/`let` (no `var`), template literals, `.trim()` on input, `camelCase` names, closes the readline interface, and Prettier leaves the file unchanged. | Imports grouped at the top with the `node:` prefix. The main flow is easy to follow (for example, a small `main()` function). | `var`, string concatenation everywhere, program hangs at exit, formatter not applied. |
