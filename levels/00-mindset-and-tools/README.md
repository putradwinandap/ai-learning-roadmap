# Level 00: Mindset & Tools

> Before writing real programs, set up the tools professionals use every day and learn how to learn, including how to use AI without letting it think for you.

## Goals

By the end of this level you can:

- Explain how you'll study: schedule, deliberate practice, getting unstuck.
- Move around and run commands in a terminal.
- Use Git to track changes and GitHub to publish them.
- Set up a code editor and a programming language runtime.
- Use an AI assistant as a mentor: ask good questions, verify answers, keep ownership of your code.
- Write, run and commit your first program.

## Prerequisites

None. A computer (Windows, macOS or Linux), an internet connection and a GitHub account.

## Time estimate

5–10 hours.
