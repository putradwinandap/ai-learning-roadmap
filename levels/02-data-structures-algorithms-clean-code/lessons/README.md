# Level 02 topics

Full lesson files are planned. Until then, your AI mentor teaches these topics in order (`/lesson`), using the resources below. Each topic will become `NN-topic.md`.

| # | Topic | Key ideas |
|---|---|---|
| 01 | Complexity & Big-O | Counting operations, O(1)/O(log n)/O(n)/O(n log n)/O(n²), best/average/worst case, space complexity |
| 02 | Arrays & hash maps | Dynamic arrays, hashing, collisions, when lookup is O(1), sets |
| 03 | Stacks & queues | LIFO/FIFO, undo stacks, task queues, deque |
| 04 | Linked lists | Nodes and pointers, insert/delete cost vs arrays |
| 05 | Recursion | Base case, recursive case, call stack, stack overflow, recursion vs iteration |
| 06 | Searching | Linear search, binary search and its preconditions |
| 07 | Sorting | Bubble/insertion (to understand), merge sort, quicksort, built-in sorts, stability, custom comparators |
| 08 | Trees & graphs | Binary search trees, traversal (DFS/BFS), graphs as adjacency lists |
| 09 | Modelling with objects | Classes, encapsulation, composition over inheritance, when OOP helps |
| 10 | Functional style | Immutability, pure functions, map/filter/reduce, higher-order functions |
| 11 | Clean code | Naming, function size, DRY vs. premature abstraction, comments, SOLID intro, code smells, refactoring |
| 12 | Unit testing & TDD | Test runner, arrange-act-assert, edge cases, red-green-refactor, test doubles intro |
