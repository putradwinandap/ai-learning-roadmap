# Level 02: Data Structures, Algorithms & Clean Code

> Write code that is correct, efficient *and* easy to change, and prove it with tests.

## Goals

By the end of this level you can:

- Reason about time and space complexity with Big-O.
- Choose between arrays, hash maps, sets, stacks, queues, linked lists, trees and graphs.
- Write recursive solutions and know when not to.
- Implement and use searching and sorting algorithms.
- Model a domain with objects/classes **or** functional style, and know the trade-offs.
- Apply clean-code principles: naming, small functions, DRY, SOLID basics.
- Write unit tests and practise test-driven development (TDD).
